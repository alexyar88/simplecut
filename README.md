# SimpleCut

Нативный минималистичный видеоредактор для macOS, ориентированный на YouTube
и короткие вертикальные видео.

## Уже реализовано

- импорт нескольких видео;
- проекты 9:16, 16:9 и 1:1;
- неразрушающий монтаж;
- waveform звука;
- точный playhead, split и удаление фрагментов;
- запись с выбранной камеры и микрофона;
- обнаружение внешних устройств и Continuity Camera через AVFoundation;
- текстовые и графические слои;
- перемещение слоёв прямо в preview;
- длительность, размер, поворот и прозрачность слоя;
- сохранение проекта в JSON;
- экспорт MP4 с текстом и изображениями.
- локальная транскрибация через WhisperKit/Core ML;
- скачивание быстрой Base или точной Large v3 модели;
- генерация редактируемых субтитров по таймкодам слов;
- отображение субтитров в preview и MP4-экспорте.

## Требования

- macOS 14 или новее;
- полный Xcode с совместимым macOS SDK;
- Swift 6.1 или новее.

Для локальной сборки выполните:

```sh
./Scripts/package-app.sh
open build/SimpleCut.app
```

Или открыть `Package.swift` в Xcode и запустить executable target `SimpleCut`.

Скрипт создаёт локальную source-сборку для разработки. Для переносимого
дистрибутива и notarization потребуется обычный Xcode application target:
SwiftPM генерирует для зависимостей resource paths, привязанные к каталогу
сборки.

## Локальные субтитры

Выберите модель в инспекторе и нажмите `Субтитры`. При первом запуске SimpleCut
скачает модель в `Application Support/SimpleCut/Models`, после чего инференс
выполняется на устройстве. Созданные блоки можно выбирать на таймлайне и
редактировать как обычный текст.

Следующий продуктовый срез: loudness normalization/limiter, базовая
цветокоррекция и кнопка автоматического улучшения.

## Проверки

```sh
swift test
SIMPLECUT_RUN_MODEL_TEST=1 swift test \
  --filter testLocalTranscriptionWhenEnabled
```

Второй тест синтезирует речь средствами macOS, при необходимости скачивает
Base-модель и проверяет настоящий локальный Core ML-инференс.

Обычная сборка и тесты также запускаются в GitHub Actions для каждого push и
pull request. Интеграционный тест Whisper намеренно не входит в CI, поскольку
скачивает модель и требует существенно больше времени.
